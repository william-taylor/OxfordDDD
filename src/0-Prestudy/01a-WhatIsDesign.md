// What is software design?
// ================================

For this exercise, please write down the answers to
some of the questions below. There are no "right" answers!

We will be discussing these answers in the first session of the course!

# 1. What is the purpose of software design and how is it different from coding?

Coding is implementation often from a given design. Systems can be designed in multiple bespoke ways in different paradigms. Software Design should outline the domain of the solution and coding should be implementing it.

# 2. What is "good" design and "bad" design? How can you tell them apart?

Good design supports and models the domain well. Is extensible, easy to pickup and should be safe through smart design and modelling.

# 3. If you are beginning a new project, how do you start with the design?

Model at a high level before breaking it down into it's implementation. 

# 4. What is the hardest part of design. What is most likely to make a design fail?

Capturing the full scope of the domain in an extensible way that doesn't require major reworks later on.
